# Citta

A research application for a continuing agent with identity, sourced memory, commitments, internally originated interests/activity, contextual appraisal and accountable action, alongside a separately sourced Theravada Abhidhamma simulator.

Start with the [documentation index](doc/README.md). The [approved architecture](doc/design/architecture.md) and [behavior flows](doc/design/behavior-flows.md) define the target; the [development plan](doc/delivery/plan.md) and [status](doc/delivery/status.md) guide implementation. The legacy prototype is preserved alongside the new continuing-runtime source. The new runtime is implemented but not yet verified; consult status before treating it as working mode.

For setup and existing commands, use [local operations](doc/operations/local.md). Follow [project instructions](AGENTS.md) before changing or running code.
