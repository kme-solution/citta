# Citta / vinnana (စိတ် / ဝိညာဏ်) — ဗုဒ္ဓဒေသနာနှင့် ရှင်းလင်းချက်

ဤစာတမ်းသည် citta ဆိုင်ရာ လေ့လာမှုဖြစ်သည်။ [ဒစ်ဂျစ်တယ်ပုံစံ](02-digital-model.md) နှင့် [အကောင်အထည်ဖော်ပုံ](03-implementation.md) ကို သီးခြားဖတ်ပါ။ လေ့လာရက် ၂၀၂၆-၁၁-၂၃။ မြန်မာစာသည် အနှစ်ချုပ်ရှင်းလင်းချက်ဖြစ်ပြီး အတည်ပြုပါဠိဘာသာပြန် မဟုတ်ပါ။

## ၁။ အရင်းအမြစ်နှင့် အလွှာ

- CI-S1: [MN 43 — Mahavedalla](https://www.dhammatalks.org/suttas/MN/MN43.html) — နိကာယ်သုတ်အတွင်း သာရိပုတ္တရာ၏ ရှင်းလင်းချက်။ ဝိညာဏ်နှင့် ပညာ၊ ဝေဒနာ၊ သညာတို့ ဆက်စပ်ပုံ

သုတ်လင့်ခ်များမှာ Thanissaro Bhikkhu ၏ အင်္ဂလိပ်ဘာသာပြန်များ ဖြစ်သည်။ လက်စွဲကို ကိုးကားထားလျှင် BPS 2007 တတိယအကြိမ်၊ Narada ဘာသာပြန်၊ Bhikkhu Bodhi ပြင်ဆင်တည်းဖြတ်၊ U Rewata Dhamma နှင့် Bhikkhu Bodhi ရှင်းလင်းချက်များပါသော စာအုပ်ကို ဆိုလိုသည်။ နောက်ပိုင်းရှင်းလင်းချက်ကို ဗုဒ္ဓ၏ တိုက်ရိုက်မိန့်ကြားချက်ဟု မတင်ပြပါ။

## ၂။ အဓိကသဘော

MN 43 တွင် သာရိပုတ္တရာက ဝိညာဏ်နှင့် ပညာကို ခွဲခြားရှင်းပြသကဲ့သို့ ဆက်စပ်ဖြစ်ပုံကိုလည်း ဖော်ပြထားသည်။ ဝေဒနာ၊ သညာနှင့် ဝိညာဏ်တို့ကို လုံးဝသီးခြားစီ ခွဲထုတ်နိုင်သော အရာများအဖြစ် မရှင်းပြပါ။ ဤသည်မှာ သုတ်အတွင်း သာရိပုတ္တရာ၏ ဖြေကြားချက်ဖြစ်သည်။

## ၃။ ခွဲခြားနားလည်ရမည့် အချက်များ

Citta နှင့် vinnana ကို အကြောင်းအရာတိုင်းတွင် အဓိပ္ပါယ်တစ်ထပ်တည်းဟု မသတ်မှတ်ပါ။ ယခုစာတမ်းက software ၏ လက်ရှိစဉ်းစားချက်ကို တစ်စုတစ်စည်းတည်း မှတ်တမ်းထားရန် ဆက်စပ်လေ့လာခြင်း ဖြစ်သည်။ Catalog ထဲရှိ စိတ်အမျိုးအစားနှင့် runtime record ကို မညီမျှစေရပါ။

## ၄။ လေ့လာမှုနှင့် အသုံးချမှု၏ နယ်နိမိတ်

ဤသည်မှာ သက်ဆိုင်ရာ အရင်းအမြစ်အချို့ကို အခြေခံသော လေ့လာမှုဖြစ်ပြီး ဗုဒ္ဓစာပေအားလုံး၏ ပြည့်စုံသော အနက်ဖွင့်ဆိုချက် မဟုတ်ပါ။ မြန်မာဝေါဟာရကို ကျွမ်းကျင်သူဖြင့် ဆက်လက်စိစစ်နိုင်သည်။ Software နာမည်၊ မှတ်တမ်း သို့မဟုတ် အလုပ်အောင်မြင်မှုက စိတ်ရှိခြင်း၊ အမှန်တကယ် ခံစားသိမြင်ခြင်း သို့မဟုတ် မဂ်ဖိုလ်ရရှိခြင်း၏ သက်သေ မဟုတ်ပါ။ ဒုတိယစာတမ်းရှိ စည်းမျဉ်းများသည် စီမံကိန်း၏ အင်ဂျင်နီယာဆိုင်ရာ အဓိပ္ပါယ်ဖော်မှုများ ဖြစ်သည်။
