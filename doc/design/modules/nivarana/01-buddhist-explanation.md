# Nivarana (နီဝရဏ) — ဗုဒ္ဓဒေသနာနှင့် ရှင်းလင်းချက်

ဤစာတမ်းသည် nivarana ဆိုင်ရာ လေ့လာမှုဖြစ်သည်။ [ဒစ်ဂျစ်တယ်ပုံစံ](02-digital-model.md) နှင့် [အကောင်အထည်ဖော်ပုံ](03-implementation.md) ကို သီးခြားဖတ်ပါ။ လေ့လာရက် ၂၀၂၆-၁၁-၂၃။ မြန်မာစာသည် အနှစ်ချုပ်ရှင်းလင်းချက်ဖြစ်ပြီး အတည်ပြုပါဠိဘာသာပြန် မဟုတ်ပါ။

## ၁။ အရင်းအမြစ်နှင့် အလွှာ

- NI-S1: [SN 46.51 — Ahara](https://www.dhammatalks.org/suttas/SN/SN46_51.html) — နိကာယ်သုတ်။ နီဝရဏနှင့် ဗောဇ္ဈင်တို့ကို အားပေး/အားမပေးပုံ

သုတ်လင့်ခ်များမှာ Thanissaro Bhikkhu ၏ အင်္ဂလိပ်ဘာသာပြန်များ ဖြစ်သည်။ လက်စွဲကို ကိုးကားထားလျှင် BPS 2007 တတိယအကြိမ်၊ Narada ဘာသာပြန်၊ Bhikkhu Bodhi ပြင်ဆင်တည်းဖြတ်၊ U Rewata Dhamma နှင့် Bhikkhu Bodhi ရှင်းလင်းချက်များပါသော စာအုပ်ကို ဆိုလိုသည်။ နောက်ပိုင်းရှင်းလင်းချက်ကို ဗုဒ္ဓ၏ တိုက်ရိုက်မိန့်ကြားချက်ဟု မတင်ပြပါ။

## ၂။ အဓိကသဘော

SN 46.51 တွင် နီဝရဏများ ဖြစ်ပေါ်တိုးပွားစေသော အခြေအနေများနှင့် အားမပေးသော အခြေအနေများကို ဖော်ပြထားသည်။ ဆန္ဒရာဂ၊ ဗျာပါဒ၊ ထိနမိဒ္ဓ၊ ဥဒ္ဓစ္စကုက္ကုစ္စနှင့် ဝိစိကိစ္ဆာတို့ကို သက်ဆိုင်ရာ နယ်ပယ်အလိုက် လေ့လာရသည်။

## ၃။ ခွဲခြားနားလည်ရမည့် အချက်များ

Software က topic ပြောင်းလဲခြင်း၊ inference ကြာခြင်း သို့မဟုတ် မသေချာမှုရှိခြင်းကို နီဝရဏအမှန်ဟု မသတ်မှတ်ရပါ။ မသေချာခြင်းသည် သက်သေမလုံလောက်မှုကို မှန်ကန်စွာ အသိအမှတ်ပြုခြင်းလည်း ဖြစ်နိုင်သည်။ နောက်ပိုင်းထေရဝါဒစာရင်းကွဲများနှင့် ယခုသုတ်၏ ငါးမျိုးခွဲပုံကို မရောရပါ။

## ၄။ လေ့လာမှုနှင့် အသုံးချမှု၏ နယ်နိမိတ်

ဤသည်မှာ သက်ဆိုင်ရာ အရင်းအမြစ်အချို့ကို အခြေခံသော လေ့လာမှုဖြစ်ပြီး ဗုဒ္ဓစာပေအားလုံး၏ ပြည့်စုံသော အနက်ဖွင့်ဆိုချက် မဟုတ်ပါ။ မြန်မာဝေါဟာရကို ကျွမ်းကျင်သူဖြင့် ဆက်လက်စိစစ်နိုင်သည်။ Software နာမည်၊ မှတ်တမ်း သို့မဟုတ် အလုပ်အောင်မြင်မှုက စိတ်ရှိခြင်း၊ အမှန်တကယ် ခံစားသိမြင်ခြင်း သို့မဟုတ် မဂ်ဖိုလ်ရရှိခြင်း၏ သက်သေ မဟုတ်ပါ။ ဒုတိယစာတမ်းရှိ စည်းမျဉ်းများသည် စီမံကိန်း၏ အင်ဂျင်နီယာဆိုင်ရာ အဓိပ္ပါယ်ဖော်မှုများ ဖြစ်သည်။
