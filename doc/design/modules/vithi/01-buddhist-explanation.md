# Vithi (ဝီထိ) — application runtime — ဗုဒ္ဓဒေသနာနှင့် ရှင်းလင်းချက်

ဤစာတမ်းသည် vithi ဆိုင်ရာ လေ့လာမှုဖြစ်သည်။ [ဒစ်ဂျစ်တယ်ပုံစံ](02-digital-model.md) နှင့် [အကောင်အထည်ဖော်ပုံ](03-implementation.md) ကို သီးခြားဖတ်ပါ။ လေ့လာရက် ၂၀၂၆-၁၁-၂၂။ မြန်မာစာသည် အနှစ်ချုပ်ရှင်းလင်းချက်ဖြစ်ပြီး အတည်ပြုပါဠိဘာသာပြန် မဟုတ်ပါ။

## ၁။ အရင်းအမြစ်နှင့် အလွှာ

- VT-S1: [Manual of Abhidhamma](https://www.abhidhamma.org/wp-content/uploads/2025/05/bp304s_Bfodhi_Comprehensive_Manual_of_Abhidhamma.pdf) — နောက်ပိုင်း ထေရဝါဒလက်စွဲ။ အခန်း IV၊ ဝီထိဆိုင်ရာ အပိုင်း

သုတ်လင့်ခ်များမှာ Thanissaro Bhikkhu ၏ အင်္ဂလိပ်ဘာသာပြန်များ ဖြစ်သည်။ လက်စွဲကို ကိုးကားထားလျှင် BPS 2007 တတိယအကြိမ်၊ Narada ဘာသာပြန်၊ Bhikkhu Bodhi ပြင်ဆင်တည်းဖြတ်၊ U Rewata Dhamma နှင့် Bhikkhu Bodhi ရှင်းလင်းချက်များပါသော စာအုပ်ကို ဆိုလိုသည်။ နောက်ပိုင်းရှင်းလင်းချက်ကို ဗုဒ္ဓ၏ တိုက်ရိုက်မိန့်ကြားချက်ဟု မတင်ပြပါ။

## ၂။ အဓိကသဘော

ဝီထိဆိုင်ရာ နောက်ပိုင်း ထေရဝါဒရှင်းလင်းချက်ကို [citta-vithi စာတမ်း](../citta-vithi/01-buddhist-explanation.md) တွင် သီးခြားထားသည်။ ယခု module သည် application runtime အတွက် အမည်ယူထားခြင်း ဖြစ်သည်။

## ၃။ ခွဲခြားနားလည်ရမည့် အချက်များ

Temporal workflow၊ CPU tick နှင့် database transaction တို့ကို ဗုဒ္ဓစာပေပါ စိတ္တက္ခဏဟု မသတ်မှတ်ပါ။ ဝီထိအမည်တူနေခြင်းကြောင့် runtime သည် အဘိဓမ္မာဝီထိကို အမှန်တကယ် ဖြစ်ပေါ်စေသည်ဟု မဆိုနိုင်ပါ။ တစ်ခုတည်းသော foreground owner သည် အင်ဂျင်နီယာဆိုင်ရာ စည်းကမ်း ဖြစ်သည်။

## ၄။ လေ့လာမှုနှင့် အသုံးချမှု၏ နယ်နိမိတ်

ဤသည်မှာ သက်ဆိုင်ရာ အရင်းအမြစ်အချို့ကို အခြေခံသော လေ့လာမှုဖြစ်ပြီး ဗုဒ္ဓစာပေအားလုံး၏ ပြည့်စုံသော အနက်ဖွင့်ဆိုချက် မဟုတ်ပါ။ မြန်မာဝေါဟာရကို ကျွမ်းကျင်သူဖြင့် ဆက်လက်စိစစ်နိုင်သည်။ Software နာမည်၊ မှတ်တမ်း သို့မဟုတ် အလုပ်အောင်မြင်မှုက စိတ်ရှိခြင်း၊ အမှန်တကယ် ခံစားသိမြင်ခြင်း သို့မဟုတ် မဂ်ဖိုလ်ရရှိခြင်း၏ သက်သေ မဟုတ်ပါ။ ဒုတိယစာတမ်းရှိ စည်းမျဉ်းများသည် စီမံကိန်း၏ အင်ဂျင်နီယာဆိုင်ရာ အဓိပ္ပါယ်ဖော်မှုများ ဖြစ်သည်။
