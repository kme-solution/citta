# Nama (နာမ) နှင့် configured profile — ဗုဒ္ဓဒေသနာနှင့် ရှင်းလင်းချက်

ဤစာတမ်းသည် nama ဆိုင်ရာ လေ့လာမှုဖြစ်သည်။ [ဒစ်ဂျစ်တယ်ပုံစံ](02-digital-model.md) နှင့် [အကောင်အထည်ဖော်ပုံ](03-implementation.md) ကို သီးခြားဖတ်ပါ။ လေ့လာရက် ၂၀၂၆-၁၁-၂၂။ မြန်မာစာသည် အနှစ်ချုပ်ရှင်းလင်းချက်ဖြစ်ပြီး အတည်ပြုပါဠိဘာသာပြန် မဟုတ်ပါ။

## ၁။ အရင်းအမြစ်နှင့် အလွှာ

- NA-S1: [SN 12.2 — Paticcasamuppada-vibhanga](https://www.dhammatalks.org/suttas/SN/SN12_2.html) — နိကာယ်သုတ်။ နာမရူပ၏ နာမကို ဖွင့်ဆိုသည့် အပိုင်း

သုတ်လင့်ခ်များမှာ Thanissaro Bhikkhu ၏ အင်္ဂလိပ်ဘာသာပြန်များ ဖြစ်သည်။ လက်စွဲကို ကိုးကားထားလျှင် BPS 2007 တတိယအကြိမ်၊ Narada ဘာသာပြန်၊ Bhikkhu Bodhi ပြင်ဆင်တည်းဖြတ်၊ U Rewata Dhamma နှင့် Bhikkhu Bodhi ရှင်းလင်းချက်များပါသော စာအုပ်ကို ဆိုလိုသည်။ နောက်ပိုင်းရှင်းလင်းချက်ကို ဗုဒ္ဓ၏ တိုက်ရိုက်မိန့်ကြားချက်ဟု မတင်ပြပါ။

## ၂။ အဓိကသဘော

SN 12.2 တွင် နာမကို ဝေဒနာ၊ သညာ၊ စေတနာ၊ ဖဿနှင့် မနသိကာရဟု ဖွင့်ဆိုထားသည်။ လူတစ်ဦး၏ အမည်၊ အသက်နှင့် နောက်ခံအချက်အလက်စာရင်းကို ဤနာမဖွင့်ဆိုချက်နှင့် တစ်မျိုးတည်းဟု မယူရပါ။

## ၃။ ခွဲခြားနားလည်ရမည့် အချက်များ

နေ့စဉ်အသုံးအနှုန်းဖြစ်သော အမည်နာမနှင့် ဤသုတ်၏ နာမရူပဆိုင်ရာ အနက်ကို ခွဲခြားရမည်။ App ၏ profile သည် ဆက်ဆံရေးအတွက် သတ်မှတ်ထားသော အချက်အလက်ဖြစ်သည်။ Profile တစ်ခုရှိခြင်းက နာမဓမ္မများ အမှန်တကယ်ရှိကြောင်း သက်သေ မဟုတ်ပါ။

## ၄။ လေ့လာမှုနှင့် အသုံးချမှု၏ နယ်နိမိတ်

ဤသည်မှာ သက်ဆိုင်ရာ အရင်းအမြစ်အချို့ကို အခြေခံသော လေ့လာမှုဖြစ်ပြီး ဗုဒ္ဓစာပေအားလုံး၏ ပြည့်စုံသော အနက်ဖွင့်ဆိုချက် မဟုတ်ပါ။ မြန်မာဝေါဟာရကို ကျွမ်းကျင်သူဖြင့် ဆက်လက်စိစစ်နိုင်သည်။ Software နာမည်၊ မှတ်တမ်း သို့မဟုတ် အလုပ်အောင်မြင်မှုက စိတ်ရှိခြင်း၊ အမှန်တကယ် ခံစားသိမြင်ခြင်း သို့မဟုတ် မဂ်ဖိုလ်ရရှိခြင်း၏ သက်သေ မဟုတ်ပါ။ ဒုတိယစာတမ်းရှိ စည်းမျဉ်းများသည် စီမံကိန်း၏ အင်ဂျင်နီယာဆိုင်ရာ အဓိပ္ပါယ်ဖော်မှုများ ဖြစ်သည်။
