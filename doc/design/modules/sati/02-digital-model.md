# Sati (သတိ) — digital model

**State:** researched design specification; this file does not certify implementation. Read [Myanmar explanation](01-buddhist-explanation.md) before this document and [implementation design](03-implementation.md) afterward. Actual delivery evidence belongs to [status](../../../delivery/status.md).

## Purpose and interpretation

Sati provides sourced retention and relevant recollection for the same individual across communication contexts. Its limited software responsibility includes correction lineage, valid retrieval and preserving the current concern; it does not claim the Buddhist mindfulness faculty.

The source identifiers ST-S1 onward belong to document 01. The requirements below are original engineering choices informed by that research, not statements attributed to the Buddha. Source-layer and terminology limits in document 01 apply. No database field, model response or software timing establishes a literal mental factor.

## Behavioral requirements

### ST-01 — Source-preserving retention

Separate operator reports, observed content, configured identity and inferred conclusions; retain source IDs, timestamps and corrections.

### ST-02 — One individual

Relevant agent memory can cross conversations while authorization/ownership remains agent-scoped. A communication preference stays conversation-scoped unless explicitly changed.

### ST-03 — Useful retrieval

Select by current object, concern and source validity, not merely latest rows. Explain omissions and preserve mandatory request/criterion/object lineage.

### ST-04 — Correction over repetition

Invalidate superseded claims before pending proposal adoption. Repeating an old note or adviser claim cannot restore it as fact.

### ST-05 — Bounded context

Never silently drop the actual request or current criterion to fit. Distinguish excerpted source from full content; surface a genuine budget failure honestly.

## Cooperation and ownership

Sati retains/retrieves; sanna interprets; manasikara orients; chanda supplies concerns; cetana coordinates direction. Codex working threads are a cache/context aid, not authoritative Citta memory.
