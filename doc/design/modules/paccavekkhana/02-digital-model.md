# Paccavekkhana (ပစ္စဝေက္ခဏာ) — digital model

**State:** researched design specification; this file does not certify implementation. Read [Myanmar explanation](01-buddhist-explanation.md) before this document and [implementation design](03-implementation.md) afterward. Actual delivery evidence belongs to [status](../../../delivery/status.md).

## Purpose and interpretation

Paccavekkhana compares actual outcomes with the retained intention and criterion, records discrepancies and uncertainty, and supports a justified next direction. Operational review and semantic consequence review must remain distinct.

The source identifiers PA-S1 onward belong to document 01. The requirements below are original engineering choices informed by that research, not statements attributed to the Buddha. Source-layer and terminology limits in document 01 apply. No database field, model response or software timing establishes a literal mental factor.

## Behavioral requirements

### PA-01 — Criterion-preserving comparison

Compare the original criterion and adopted purpose against actual evidence. Provider completion, file return and delivered input do not establish a broad task outcome.

### PA-02 — Uncertainty and reconciliation

Unknown effects block blind redispatch. Missing observations yield unknown, not met.

### PA-03 — Consequences beyond return status

Record predicted versus actual result and material side effects/affected resources. Preserve contradictions rather than rationalize a preferred result.

### PA-04 — Next justified direction

Recommend continuation, correction, clarification, release or reconciliation with evidence and reason; a review cannot grant new authority.

### PA-05 — Retained learning

Only attributable reviewed findings enter derived memory or bounded inclination updates. Private prose saying "I learned" is not a state change.

## Cooperation and ownership

Kamma performs; paccavekkhana compares; sati retains findings; cetana chooses a subsequent direction; vithi persists transitions. Reconstructed activity descriptions are not independent instrumentation.
