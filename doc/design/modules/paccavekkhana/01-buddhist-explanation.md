# Paccavekkhana (ပစ္စဝေက္ခဏာ) — ဗုဒ္ဓဒေသနာနှင့် ရှင်းလင်းချက်

ဤစာတမ်းသည် paccavekkhana ဆိုင်ရာ လေ့လာမှုဖြစ်သည်။ [ဒစ်ဂျစ်တယ်ပုံစံ](02-digital-model.md) နှင့် [အကောင်အထည်ဖော်ပုံ](03-implementation.md) ကို သီးခြားဖတ်ပါ။ လေ့လာရက် ၂၀၂၆-၁၁-၂၂။ မြန်မာစာသည် အနှစ်ချုပ်ရှင်းလင်းချက်ဖြစ်ပြီး အတည်ပြုပါဠိဘာသာပြန် မဟုတ်ပါ။

## ၁။ အရင်းအမြစ်နှင့် အလွှာ

- PA-S1: [MN 61 — Ambalatthika-rahulovada](https://www.dhammatalks.org/suttas/MN/MN61.html) — နိကာယ်သုတ်။ ပြုမူမှုကို ပြန်လည်ဆင်ခြင်သည့် အပိုင်း

သုတ်လင့်ခ်များမှာ Thanissaro Bhikkhu ၏ အင်္ဂလိပ်ဘာသာပြန်များ ဖြစ်သည်။ လက်စွဲကို ကိုးကားထားလျှင် BPS 2007 တတိယအကြိမ်၊ Narada ဘာသာပြန်၊ Bhikkhu Bodhi ပြင်ဆင်တည်းဖြတ်၊ U Rewata Dhamma နှင့် Bhikkhu Bodhi ရှင်းလင်းချက်များပါသော စာအုပ်ကို ဆိုလိုသည်။ နောက်ပိုင်းရှင်းလင်းချက်ကို ဗုဒ္ဓ၏ တိုက်ရိုက်မိန့်ကြားချက်ဟု မတင်ပြပါ။

## ၂။ အဓိကသဘော

MN 61 ၏ ပြုမူမှုဆိုင်ရာ ဆင်ခြင်ပုံကို [cetana သုတေသနစာတမ်း](../cetana/01-buddhist-explanation.md) တွင် ရှင်းလင်းထားသည်။ ဤနေရာတွင် ပစ္စဝေက္ခဏာကို ပြန်လည်ဆင်ခြင်သုံးသပ်ခြင်းဟူသော လုပ်ငန်းသဘောဖြင့် ဆက်စပ်လေ့လာသည်။

## ၃။ ခွဲခြားနားလည်ရမည့် အချက်များ

ပြန်လည်ဆင်ခြင်ခြင်းကို error ရှိမရှိ စစ်ဆေးခြင်းနှင့်သာ မညီမျှစေရပါ။ Software က အောင်မြင်ကြောင်း ပြန်ပို့ခြင်းသည် ရည်ရွယ်ခဲ့သည့် အကျိုးနှင့် အခြားအကျိုးဆက်များကို သိရှိပြီးကြောင်း မဆိုလိုပါ။ နောက်ပိုင်းစာပေရှိ မဂ်ဖိုလ်ပစ္စဝေက္ခဏာဆိုင်ရာ အဓိပ္ပါယ်ကို ယခု app ၏ review log နှင့် မရောထွေးရပါ။

## ၄။ လေ့လာမှုနှင့် အသုံးချမှု၏ နယ်နိမိတ်

ဤသည်မှာ သက်ဆိုင်ရာ အရင်းအမြစ်အချို့ကို အခြေခံသော လေ့လာမှုဖြစ်ပြီး ဗုဒ္ဓစာပေအားလုံး၏ ပြည့်စုံသော အနက်ဖွင့်ဆိုချက် မဟုတ်ပါ။ မြန်မာဝေါဟာရကို ကျွမ်းကျင်သူဖြင့် ဆက်လက်စိစစ်နိုင်သည်။ Software နာမည်၊ မှတ်တမ်း သို့မဟုတ် အလုပ်အောင်မြင်မှုက စိတ်ရှိခြင်း၊ အမှန်တကယ် ခံစားသိမြင်ခြင်း သို့မဟုတ် မဂ်ဖိုလ်ရရှိခြင်း၏ သက်သေ မဟုတ်ပါ။ ဒုတိယစာတမ်းရှိ စည်းမျဉ်းများသည် စီမံကိန်း၏ အင်ဂျင်နီယာဆိုင်ရာ အဓိပ္ပါယ်ဖော်မှုများ ဖြစ်သည်။
