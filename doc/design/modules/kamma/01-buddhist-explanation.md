# Kamma (ကံ) — ဗုဒ္ဓဒေသနာနှင့် ရှင်းလင်းချက်

ဤစာတမ်းသည် kamma ဆိုင်ရာ လေ့လာမှုဖြစ်သည်။ [ဒစ်ဂျစ်တယ်ပုံစံ](02-digital-model.md) နှင့် [အကောင်အထည်ဖော်ပုံ](03-implementation.md) ကို သီးခြားဖတ်ပါ။ လေ့လာရက် ၂၀၂၆-၁၁-၂၂။ မြန်မာစာသည် အနှစ်ချုပ်ရှင်းလင်းချက်ဖြစ်ပြီး အတည်ပြုပါဠိဘာသာပြန် မဟုတ်ပါ။

## ၁။ အရင်းအမြစ်နှင့် အလွှာ

- KA-S1: [AN 6.63 — Nibbedhika](https://www.dhammatalks.org/suttas/AN/AN6_63.html) — နိကာယ်သုတ်။ စေတနာနှင့် ကိုယ်၊ နှုတ်၊ စိတ်ဖြင့် ပြုမှု

သုတ်လင့်ခ်များမှာ Thanissaro Bhikkhu ၏ အင်္ဂလိပ်ဘာသာပြန်များ ဖြစ်သည်။ လက်စွဲကို ကိုးကားထားလျှင် BPS 2007 တတိယအကြိမ်၊ Narada ဘာသာပြန်၊ Bhikkhu Bodhi ပြင်ဆင်တည်းဖြတ်၊ U Rewata Dhamma နှင့် Bhikkhu Bodhi ရှင်းလင်းချက်များပါသော စာအုပ်ကို ဆိုလိုသည်။ နောက်ပိုင်းရှင်းလင်းချက်ကို ဗုဒ္ဓ၏ တိုက်ရိုက်မိန့်ကြားချက်ဟု မတင်ပြပါ။

## ၂။ အဓိကသဘော

AN 6.63 ဆိုင်ရာ အဓိကရှင်းလင်းချက်ကို [cetana စာတမ်း](../cetana/01-buddhist-explanation.md) တွင် ဖော်ပြထားသည်။ ဤနေရာတွင် ကံကို ပြင်ပလုပ်ဆောင်ချက်တစ်ခု အောင်မြင်သွားခြင်းနှင့်သာ မညီမျှစေရန် အထူးမှတ်သားရမည်။

## ၃။ ခွဲခြားနားလည်ရမည့် အချက်များ

HTTP request၊ file read သို့မဟုတ် keyboard input တို့ကို ဗုဒ္ဓစာပေပါ ကံနှင့် ကံအကျိုး အပြည့်အစုံဟု မတင်ပြရပါ။ စေတနာ၊ လုပ်ဆောင်မှုနှင့် ပြန်ရလာသော အထောက်အထားကို ခွဲခြားထားရမည်။ လုပ်ဆောင်မှုအမည်ကို Pali ဖြင့် ပေးထားခြင်းက ထိုနယ်နိမိတ်ကို မဖယ်ရှားပါ။

## ၄။ လေ့လာမှုနှင့် အသုံးချမှု၏ နယ်နိမိတ်

ဤသည်မှာ သက်ဆိုင်ရာ အရင်းအမြစ်အချို့ကို အခြေခံသော လေ့လာမှုဖြစ်ပြီး ဗုဒ္ဓစာပေအားလုံး၏ ပြည့်စုံသော အနက်ဖွင့်ဆိုချက် မဟုတ်ပါ။ မြန်မာဝေါဟာရကို ကျွမ်းကျင်သူဖြင့် ဆက်လက်စိစစ်နိုင်သည်။ Software နာမည်၊ မှတ်တမ်း သို့မဟုတ် အလုပ်အောင်မြင်မှုက စိတ်ရှိခြင်း၊ အမှန်တကယ် ခံစားသိမြင်ခြင်း သို့မဟုတ် မဂ်ဖိုလ်ရရှိခြင်း၏ သက်သေ မဟုတ်ပါ။ ဒုတိယစာတမ်းရှိ စည်းမျဉ်းများသည် စီမံကိန်း၏ အင်ဂျင်နီယာဆိုင်ရာ အဓိပ္ပါယ်ဖော်မှုများ ဖြစ်သည်။
