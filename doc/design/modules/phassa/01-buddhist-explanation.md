# Phassa (ဖဿ) — ဗုဒ္ဓဒေသနာနှင့် ရှင်းလင်းချက်

ဤစာတမ်းသည် phassa ဆိုင်ရာ လေ့လာမှုဖြစ်သည်။ [ဒစ်ဂျစ်တယ်ပုံစံ](02-digital-model.md) နှင့် [အကောင်အထည်ဖော်ပုံ](03-implementation.md) ကို သီးခြားဖတ်ပါ။ လေ့လာရက် ၂၀၂၆-၁၁-၂၂။ မြန်မာစာသည် အနှစ်ချုပ်ရှင်းလင်းချက်ဖြစ်ပြီး အတည်ပြုပါဠိဘာသာပြန် မဟုတ်ပါ။

## ၁။ အရင်းအမြစ်နှင့် အလွှာ

- PH-S1: [MN 148 — Chachakka](https://www.dhammatalks.org/suttas/MN/MN148.html) — နိကာယ်သုတ်။ အာယတန၊ ဝိညာဏ်နှင့် ဖဿဆိုင်ရာ အပိုင်း
- PH-S2: [SN 12.2 — Paticcasamuppada-vibhanga](https://www.dhammatalks.org/suttas/SN/SN12_2.html) — နိကာယ်သုတ်။ ဖဿအမျိုးအစားများ၏ အဓိပ္ပါယ်

သုတ်လင့်ခ်များမှာ Thanissaro Bhikkhu ၏ အင်္ဂလိပ်ဘာသာပြန်များ ဖြစ်သည်။ လက်စွဲကို ကိုးကားထားလျှင် BPS 2007 တတိယအကြိမ်၊ Narada ဘာသာပြန်၊ Bhikkhu Bodhi ပြင်ဆင်တည်းဖြတ်၊ U Rewata Dhamma နှင့် Bhikkhu Bodhi ရှင်းလင်းချက်များပါသော စာအုပ်ကို ဆိုလိုသည်။ နောက်ပိုင်းရှင်းလင်းချက်ကို ဗုဒ္ဓ၏ တိုက်ရိုက်မိန့်ကြားချက်ဟု မတင်ပြပါ။

## ၂။ အဓိကသဘော

MN 148 တွင် အာယတန၊ အာရုံနှင့် သက်ဆိုင်ရာ ဝိညာဏ်ကို အခြေခံသော တွေ့ဆုံမှုကို ဖဿဟု ဖော်ပြထားသည်။ SN 12.2 တွင်လည်း ဖဿကို ခြောက်မျိုး ခွဲဖော်ပြထားသည်။

## ၃။ ခွဲခြားနားလည်ရမည့် အချက်များ

ဖဿသည် ကိုယ်ခန္ဓာချင်း ထိခြင်းတစ်ခုတည်းကို ဆိုလိုခြင်း မဟုတ်ပါ။ Message receipt၊ network connection နှင့် screenshot file ရှိခြင်းတို့ကို ဖဿအမှန်ဟု မတင်ပြရပါ။ Software အတွက် ဆက်စပ်မှတ်တမ်းထားပုံကို ဒုတိယစာတမ်းတွင် သီးခြားသတ်မှတ်မည်။

## ၄။ လေ့လာမှုနှင့် အသုံးချမှု၏ နယ်နိမိတ်

ဤသည်မှာ သက်ဆိုင်ရာ အရင်းအမြစ်အချို့ကို အခြေခံသော လေ့လာမှုဖြစ်ပြီး ဗုဒ္ဓစာပေအားလုံး၏ ပြည့်စုံသော အနက်ဖွင့်ဆိုချက် မဟုတ်ပါ။ မြန်မာဝေါဟာရကို ကျွမ်းကျင်သူဖြင့် ဆက်လက်စိစစ်နိုင်သည်။ Software နာမည်၊ မှတ်တမ်း သို့မဟုတ် အလုပ်အောင်မြင်မှုက စိတ်ရှိခြင်း၊ အမှန်တကယ် ခံစားသိမြင်ခြင်း သို့မဟုတ် မဂ်ဖိုလ်ရရှိခြင်း၏ သက်သေ မဟုတ်ပါ။ ဒုတိယစာတမ်းရှိ စည်းမျဉ်းများသည် စီမံကိန်း၏ အင်ဂျင်နီယာဆိုင်ရာ အဓိပ္ပါယ်ဖော်မှုများ ဖြစ်သည်။
