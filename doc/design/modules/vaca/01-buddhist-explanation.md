# Vaca (ဝါစာ) — ဗုဒ္ဓဒေသနာနှင့် ရှင်းလင်းချက်

ဤစာတမ်းသည် vaca ဆိုင်ရာ လေ့လာမှုဖြစ်သည်။ [ဒစ်ဂျစ်တယ်ပုံစံ](02-digital-model.md) နှင့် [အကောင်အထည်ဖော်ပုံ](03-implementation.md) ကို သီးခြားဖတ်ပါ။ လေ့လာရက် ၂၀၂၆-၁၁-၂၂။ မြန်မာစာသည် အနှစ်ချုပ်ရှင်းလင်းချက်ဖြစ်ပြီး အတည်ပြုပါဠိဘာသာပြန် မဟုတ်ပါ။

## ၁။ အရင်းအမြစ်နှင့် အလွှာ

- VA-S1: [MN 58 — Abhaya](https://www.dhammatalks.org/suttas/MN/MN58.html) — နိကာယ်သုတ်။ သုတ်၏ အမှန်၊ အကျိုးရှိမှုနှင့် ပြောသင့်ချိန်ဆိုင်ရာ အပိုင်း၊ ဘာသာပြန်နိဒါန်းနှင့် ခွဲဖတ်ရန်

သုတ်လင့်ခ်များမှာ Thanissaro Bhikkhu ၏ အင်္ဂလိပ်ဘာသာပြန်များ ဖြစ်သည်။ လက်စွဲကို ကိုးကားထားလျှင် BPS 2007 တတိယအကြိမ်၊ Narada ဘာသာပြန်၊ Bhikkhu Bodhi ပြင်ဆင်တည်းဖြတ်၊ U Rewata Dhamma နှင့် Bhikkhu Bodhi ရှင်းလင်းချက်များပါသော စာအုပ်ကို ဆိုလိုသည်။ နောက်ပိုင်းရှင်းလင်းချက်ကို ဗုဒ္ဓ၏ တိုက်ရိုက်မိန့်ကြားချက်ဟု မတင်ပြပါ။

## ၂။ အဓိကသဘော

MN 58 တွင် အမှန်ဖြစ်မှု၊ အကျိုးရှိမှုနှင့် ပြောသင့်သောအချိန်တို့ကို ထည့်သွင်းစဉ်းစားပုံကို ဖော်ပြထားသည်။ သူတစ်ပါး နားဝင်ချိုခြင်းတစ်ခုတည်းက ပြောသင့်သော စကားဖြစ်ကြောင်း မသတ်မှတ်ပါ။ ဤအချက်ကို ဘာသာပြန်၏ နိဒါန်းမဟုတ်ဘဲ သုတ်၏ စကားအပိုင်းမှ ကိုးကားထားသည်။

## ၃။ ခွဲခြားနားလည်ရမည့် အချက်များ

ဝါစာကို string ထုတ်ပေးခြင်းနှင့်သာ မညီမျှစေရပါ။ ထို့အတူ အမှန်ကို သေချာမသိသေးသော software က မိမိစကားအားလုံး အမှန်ဟု မဆိုရပါ။ Message parsing၊ အနက်ဖွင့်ခြင်း၊ ပြောဆိုရန် စေတနာနှင့် အမှန်တကယ် ပို့ပြီးခြင်းတို့သည် သီးခြားအချက်များ ဖြစ်သည်။

## ၄။ လေ့လာမှုနှင့် အသုံးချမှု၏ နယ်နိမိတ်

ဤသည်မှာ သက်ဆိုင်ရာ အရင်းအမြစ်အချို့ကို အခြေခံသော လေ့လာမှုဖြစ်ပြီး ဗုဒ္ဓစာပေအားလုံး၏ ပြည့်စုံသော အနက်ဖွင့်ဆိုချက် မဟုတ်ပါ။ မြန်မာဝေါဟာရကို ကျွမ်းကျင်သူဖြင့် ဆက်လက်စိစစ်နိုင်သည်။ Software နာမည်၊ မှတ်တမ်း သို့မဟုတ် အလုပ်အောင်မြင်မှုက စိတ်ရှိခြင်း၊ အမှန်တကယ် ခံစားသိမြင်ခြင်း သို့မဟုတ် မဂ်ဖိုလ်ရရှိခြင်း၏ သက်သေ မဟုတ်ပါ။ ဒုတိယစာတမ်းရှိ စည်းမျဉ်းများသည် စီမံကိန်း၏ အင်ဂျင်နီယာဆိုင်ရာ အဓိပ္ပါယ်ဖော်မှုများ ဖြစ်သည်။
