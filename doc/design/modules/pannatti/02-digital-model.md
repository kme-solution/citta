# Pannatti (ပညတ်) — digital model

**State:** researched design specification; this file does not certify implementation. Read [Myanmar explanation](01-buddhist-explanation.md) before this document and [implementation design](03-implementation.md) afterward. Actual delivery evidence belongs to [status](../../../delivery/status.md).

## Purpose and interpretation

Pannatti will govern conventional designation and reference mapping: names, aliases and scoped meanings used to communicate about the same agent, people, sources and concepts. It is not a new self, universal ontology or truth engine.

The source identifiers PN-S1 onward belong to document 01. The requirements below are original engineering choices informed by that research, not statements attributed to the Buddha. Source-layer and terminology limits in document 01 apply. No database field, model response or software timing establishes a literal mental factor.

## Behavioral requirements

### PN-01 — Identity versus label

Stable entity/source IDs remain distinct from display names and localized labels. Renaming a label cannot create or erase an entity/history.

### PN-02 — Scoped aliases

An alias requires explicit scope and provenance; identical names cannot merge operator, agent or two companies automatically.

### PN-03 — Concept versus observation

A concept description or inferred entity is not an observed instance. A filename establishes availability/name, not its content.

### PN-04 — Localization

Keep stable catalog IDs and language labels separate; Myanmar terminology review status remains visible.

### PN-05 — Corrections

Version name/reference corrections and invalidate dependent interpretations when material. Do not rewrite prior communications or fabricate historical knowledge.

## Cooperation and ownership

Pannatti supplies designations; sanna interprets referents; nama currently owns profile loading; sati owns retained source history. The conceptual distinction informs software design but does not make the database an ultimate-reality classification.
