# Citta-sangaha (စိတ္တသင်္ဂဟ) — digital model

**State:** researched design specification; this file does not certify implementation. Read [Myanmar explanation](01-buddhist-explanation.md) before this document and [implementation design](03-implementation.md) afterward. Actual delivery evidence belongs to [status](../../../delivery/status.md).

## Purpose and interpretation

Citta-sangaha is the pinned doctrinal consciousness-type catalog, including stable 89/121 projections, groups and localized reference labels. It is not a classifier of Kyaw2 current consciousness or a progress score toward human-like behavior.

The source identifiers CG-S1 onward belong to document 01. The requirements below are original engineering choices informed by that research, not statements attributed to the Buddha. Source-layer and terminology limits in document 01 apply. No database field, model response or software timing establishes a literal mental factor.

## Behavioral requirements

### CG-01 — Stable projections

Preserve exact stable IDs and parent-child relations between summary/detailed cases. Count correctness alone cannot verify meaning.

### CG-02 — Source provenance

Associate groups/types with precise chapter/source version and review status. Do not invent doctrine from a group name.

### CG-03 — Localized labels

English/Myanmar labels refer to the same ID; pending translation review stays visible.

### CG-04 — Read-only boundary

Catalog calls cannot mutate identity, runtime motives, memory or goals.

### CG-05 — Honest coverage

Expose supported classifications and missing/source-review limits without claiming live attainment or conscious experience.

## Cooperation and ownership

Citta-sangaha supplies reference identities; cetasika supplies associations; citta-vithi supplies simulated sequences; pannatti clarifies labels. None of them certifies runtime mental states.

Evaluate the resulting records, next action, correction lineage and visible outcome using different contexts and paraphrases. Schema validity, a fixed sentence or a Pali folder name is insufficient. Where this is a catalog/reference boundary, evaluate source provenance and classification correctness instead of pretending it is live cognition.
