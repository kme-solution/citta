# Selecting a cognitive course

Use `npm run eye -- ear great` to inspect a hearing course. The same entry point accepts eye, ear, nose, tongue or body and the grades very-great, great, slight and very-slight. Use `npm run eye -- mind clear` or `npm run eye -- mind obscure` for an ordinary mind-door example. With no arguments the command prints the detailed 17-moment eye fixture.

These additional views show the ordered functions beginning with the disturbance of bhavaṅga. Grade controls the endpoint. Repeated determining or vibration is represented by one illustrative choice of count. The numbered positions in these shorter views are relative to the displayed disturbance. See chapter IV of the reference manual listed in Citta_Research_and_Requirements.md.
