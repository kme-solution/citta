# Citta project conventions

Write product, architecture, and operating documents under doc/ before writing code. Use ASCII Pāli names for domain modules and services. Kyaw installs dependencies, builds, runs, tests, and fixes locally. For ordinary implementation tasks, write source only. Do not create tests or execute application code, migrations, builds, or test commands unless Kyaw explicitly requests it. These conventions supersede the execution instructions and earlier English domain folder names in the reference runbook.
